## 1. 개요

워크북 이미지에서 **빨간색 네모(답안 박스)**를 자동으로 감지하고, 좌표값을 추출하는 웹 기반 도구입니다. 별도의 서버 설치 없이 HTML 파일을 브라우저에서 직접 열어 사용합니다.

### 지원 파일 형식

- PNG, JPG, JPEG, BMP

### 실행 방법

`src/` 폴더 내 HTML 파일을 더블클릭하여 브라우저에서 엽니다.

---

## 2. 도구 종류

| 도구 | 파일명 | 용도 |
|------|--------|------|
| **FolderWorkBook** | `FolderWorkBook.html` | 폴더 단위 일괄 처리, 편집, 내보내기 (메인) |
| **Red Rectangle Detector** | `index.html` | 단일 이미지 빠른 감지 및 좌표 복사 |
| **Workbook Verifier** | `workbook-verifier.html` | 일괄 처리 후 검증 확인 |

## 3. FolderWorkBook (메인 도구)

가장 기능이 풍부한 메인 도구입니다. 폴더 단위로 이미지를 불러와 일괄 감지, 편집, 검증, 내보내기를 수행합니다.

### 3.1 이미지 불러오기

**방법 1: 버튼 클릭**
- "폴더 선택하기" 버튼을 클릭하여 이미지가 들어있는 폴더를 선택합니다.

**방법 2: 드래그 앤 드롭**
- 파일 탐색기에서 폴더를 브라우저 화면에 드래그합니다.

> 이미지는 파일명 기준 알파벳순으로 자동 정렬됩니다.

### 3.2 일괄 감지 (Batch Processing)

이미지를 불러온 후 **"일괄 감지 시작"** 버튼을 누르면 모든 이미지에 대해 순차적으로 빨간 박스 감지가 실행됩니다.

- 진행률 바와 현재 처리 중인 이미지 파일명이 표시됩니다.
- 처리 완료 후 각 이미지의 결과를 확인하고 편집할 수 있습니다.

### 3.3 감지 설정 (Detection Settings)

사이드바에서 감지 파라미터를 조정할 수 있습니다.

#### 프리셋

| 프리셋 | 최소 영역 | 채도 | 밝기 | 최대 박스 수 | 용도 |
|--------|-----------|------|------|-------------|------|
| **워크북** | 25,000 | 100 | 100 | 100 | 큰 답안 박스가 있는 워크북 |
| **카드** | 800 | 120 | 120 | 50 | 작은 카드형 교재 |
| **커스텀** | 직접 설정 | 직접 설정 | 직접 설정 | 직접 설정 | 수동 조정 |

#### 개별 설정값

| 설정 | 범위 | 설명 |
|------|------|------|
| **최소 영역** (Min Area) | 100 ~ 100,000 px² | 이 면적 미만의 박스는 무시됩니다 |
| **최대 박스 수** (Max Box Count) | 1 ~ 500 | 감지할 최대 박스 개수 (면적 큰 순으로 선택) |
| **채도 하한** (Saturation) | 30 ~ 220 | 빨간색의 선명함 기준. 낮출수록 흐린 빨간색도 감지 |
| **밝기 하한** (Value) | 30 ~ 220 | 빨간색의 밝기 기준. 낮출수록 어두운 빨간색도 감지 |

#### 해상도 배율 (Resolution Scale)

| 배율 | 설명 |
|------|------|
| **1x** (원본) | 원본 해상도 그대로 사용 |
| **1.5x** (고해상도) | 1.5배 확대하여 감지 정밀도 향상 |
| **2x** (초고해상도) | 2배 확대. 작은 박스 감지에 유리 |

> 배율 변경 시 기존 좌표값도 자동으로 재계산됩니다. 확인 다이얼로그가 표시됩니다.

### 3.4 이미지 탐색

#### 네비게이션 바 (화면 하단)

| 버튼 | 기능 |
|------|------|
| **📋 목록** | 이미지 목록(플레이리스트) 패널 열기/닫기 |
| **◀ 이전** | 이전 이미지로 이동 |
| **다음 ▶** | 다음 이미지로 이동 |
| **🔍 재감지** | 현재 이미지에 감지를 다시 실행 |
| **✏️ 그리기** | 박스 수동 그리기 모드 ON/OFF |
| **🤚 이동** | 손 도구(패닝) 모드 ON/OFF |
| **📄 페이지 JSON** | 현재 페이지 좌표를 JSON으로 다운로드 |
| **✓ 검증완료** | 현재 이미지를 검증 완료로 표시 |

#### 이미지 플레이리스트

- **📋 목록** 버튼으로 열 수 있습니다.
- 드래그 가능한 그리드 형태로 모든 이미지를 표시합니다.
- 각 이미지 카드에는 페이지 번호와 검증 상태가 표시됩니다.
- 카드를 클릭하면 해당 이미지로 이동합니다.

### 3.5 화면 조작

#### 확대/축소 (Zoom)

| 조작 | 동작 |
|------|------|
| 확대 버튼 / 마우스 휠 위 | 확대 |
| 축소 버튼 / 마우스 휠 아래 | 축소 |
| 리셋 버튼 | 100%로 복원 |

- 확대 범위: 50% ~ 300%
- 현재 화면 중심을 기준으로 확대/축소됩니다.

#### 화면 이동 (Pan)

| 조작 | 동작 |
|------|------|
| **🤚 이동** 버튼 또는 **H 키** | 이동 모드 전환 |
| **Space 바** 누른 채 드래그 | 일시적 이동 (놓으면 해제) |
| 마우스 **가운데 버튼** 드래그 | 이동 |

### 3.6 박스 편집

#### 캔버스에서 직접 편집

| 동작 | 방법 |
|------|------|
| **선택** | 박스를 클릭 (테두리가 노란색으로 변함) |
| **이동** | 박스를 드래그 |
| **크기 조절** | 8방향 핸들(모서리 4개 + 변 중간 4개)을 드래그 |
| **삭제** | 박스 오른쪽 상단의 빨간 X 클릭 |

#### 수동 그리기

1. **✏️ 그리기** 버튼 또는 **P 키**를 눌러 그리기 모드를 켭니다.
2. 캔버스에서 드래그하여 새 박스를 그립니다.
3. 최소 20x20 px 이상이어야 생성됩니다.
4. 화면 좌하단에 "✏️ 그리기 모드 활성화" 표시가 나타납니다.

#### 사이드바에서 편집

각 박스 카드에서:
- **좌표 입력란** (X, Y, Width, Height)에 직접 숫자를 입력하여 수정할 수 있습니다.
- **ID** 값도 직접 수정 가능합니다.
- **✕ 버튼**으로 삭제할 수 있습니다.
- **드래그 핸들(⋮⋮)**을 잡고 드래그하여 순서를 변경할 수 있습니다.

#### 다중 선택

- 각 박스 카드의 **체크박스**를 클릭하여 다중 선택합니다.
- **선택 삭제** 버튼으로 선택된 박스를 한꺼번에 삭제합니다.
- **선택 해제** 버튼으로 모든 선택을 취소합니다.

### 3.7 검증 (Verification)

- **✓ 검증완료** 버튼 또는 **Space 바**(패닝 없이 누르고 뗄 때)로 현재 이미지의 검증 상태를 토글합니다.
- 상태는 3가지입니다:

| 상태 | 의미 |
|------|------|
| **verified** (초록) | 검증 완료 |
| **pending** (기본) | 미검증 |
| **warning** (경고) | 감지된 박스가 0개 |

- 상단 통계바에서 전체 처리/검증 현황을 실시간으로 확인할 수 있습니다.

### 3.8 내보내기 (Export)

사이드바 하단의 버튼으로 결과를 내보냅니다.

| 버튼 | 형식 | 범위 | 설명 |
|------|------|------|------|
| **💾 JSON 다운로드** | JSON | 전체 | 모든 이미지의 전체 데이터 |
| **📄 CSV 다운로드** | CSV | 전체 | 한글 지원(BOM 포함) |
| **📊 Excel (현재 페이지)** | XLSX | 현재 페이지 | 현재 보고 있는 페이지만 |
| **📊 Excel 전체 다운로드** | XLSX | 전체 | 모든 페이지 통합 |
| **📄 페이지 JSON** | JSON | 현재 페이지 | 현재 페이지 좌표만 |

#### JSON 출력 구조 (전체)

```json
{
  "project": "도요새 중국어 워크북",
  "totalImages": 10,
  "exportDate": "2026-04-01T...",
  "images": [
    {
      "filename": "page_001.png",
      "pageNumber": 1,
      "status": "verified",
      "verified": true,
      "dimensions": { "width": 1920, "height": 1080 },
      "touchAreas": [
        {
          "id": 1,
          "x": 100, "y": 200,
          "width": 300, "height": 150,
          "x2": 400, "y2": 350,
          "confidence": 0.95
        }
      ]
    }
  ]
}
```

#### CSV 열 구성

`Page | Filename | BoxID | X | Y | Width | Height | X2 | Y2 | Confidence | VerificationStatus`

> 모든 좌표값은 정수(소수점 버림)로 내보내집니다.

### 3.9 키보드 단축키

| 키 | 동작 |
|----|------|
| **← (왼쪽 화살표)** | 이전 이미지 |
| **→ (오른쪽 화살표)** | 다음 이미지 |
| **Space (꾹 누르기)** | 일시적 화면 이동 모드 |
| **Space (짧게 누르기)** | 검증 완료 토글 |
| **H** | 이동(손) 도구 토글 |
| **D** | 재감지 실행 |
| **P** | 그리기 모드 토글 |
| **Delete** | 선택된 박스 삭제 |

## 4. Red Rectangle Detector (단일 이미지)

`index.html` - 한 장의 이미지를 빠르게 분석하고 좌표를 복사할 때 사용합니다.

### 4.1 사용 흐름

1. **이미지 업로드**: 화면 중앙에 이미지를 드래그하거나 클릭하여 파일을 선택합니다.
2. **감지 실행**: **🔍 감지 실행** 버튼을 클릭합니다.
3. **결과 확인**: 감지된 박스가 초록색으로 캔버스에 표시되고, 사이드바에 좌표가 나열됩니다.
4. **좌표 복사**: **📋 전체 좌표 복사** 버튼으로 JSON을 클립보드에 복사합니다.

### 4.2 설정

| 설정 | 범위 | 기본값 |
|------|------|--------|
| 최소 영역 | 100 ~ 5,000 | 800 |
| 채도 하한 | 30 ~ 220 | 120 |
| 밝기 하한 | 30 ~ 220 | 120 |

### 4.3 주요 기능

- **오버레이 ON/OFF**: 감지 결과 표시를 켜고 끌 수 있습니다.
- **새 이미지**: 현재 이미지를 초기화하고 새 이미지를 불러옵니다.
- **결과 카드 클릭**: 해당 박스가 캔버스에서 노란색으로 강조됩니다.

## 5. Workbook Verifier (검증 도구)

`workbook-verifier.html` - 일괄 감지 후 검증에 특화된 간소화 도구입니다.

### 5.1 사용 흐름

1. **폴더 선택**: 버튼을 클릭하여 이미지 폴더를 선택합니다.
2. **자동 일괄 처리**: 선택과 동시에 모든 이미지를 순차 감지합니다.
3. **결과 확인**: 이미지를 탐색하며 감지 결과를 확인합니다.
4. **검증 표시**: **✓ 검증완료** 버튼으로 확인한 이미지를 표시합니다.
5. **내보내기**: JSON, CSV, Excel로 결과를 저장합니다.

### 5.2 설정

| 설정 | 범위 | 기본값 |
|------|------|--------|
| 최소 영역 | 100 ~ 5,000 | 500 |
| 채도 하한 | 30 ~ 220 | 100 |
| 밝기 하한 | 30 ~ 220 | 100 |

> 이 도구는 캔버스에서의 직접 편집(이동, 크기 조절, 그리기)을 지원하지 않습니다. 편집이 필요하면 FolderWorkBook을 사용하세요.

## 6. 감지 알고리즘 상세

### 6.1 빨간색 인식 과정

1. **RGB → HSV 변환**: 각 픽셀의 색상을 HSV(색상, 채도, 밝기) 공간으로 변환합니다.
2. **빨간색 필터링**: 아래 조건을 모두 만족하는 픽셀만 "빨간색"으로 판정합니다.

| 조건 | FolderWorkBook | index / verifier |
|------|----------------|------------------|
| 색상(Hue) | ≤ 5° 또는 ≥ 175° | ≤ 8° 또는 ≥ 172° |
| 채도(Saturation) | ≥ 설정값 (기본 100) | ≥ 설정값 (기본 120) |
| 밝기(Value) | ≥ 설정값 (기본 100) | ≥ 설정값 (기본 120) |

### 6.2 네모 인식 과정

1. **연결 요소 탐색**: 4-connectivity(상하좌우) 방식으로 인접한 빨간 픽셀들을 하나의 덩어리로 묶습니다.
2. **바운딩 박스 계산**: 각 덩어리의 최소/최대 x, y 좌표로 직사각형을 만듭니다.
3. **필터링**: 아래 조건에 해당하면 제외됩니다.

| 필터 | 조건 | 설명 |
|------|------|------|
| 최소 면적 | width × height < minArea | 너무 작은 네모 제외 |
| 종횡비 | max(w,h) / min(w,h) ≥ 20 | 가느다란 선 모양 제외 |

4. **겹침 병합**: 두 박스의 바운딩 박스가 일정 비율 이상 겹치면 하나로 합칩니다.

| 도구 | 병합 기준 |
|------|-----------|
| FolderWorkBook | 작은 쪽 면적의 **20%** 초과 겹침 |
| index / verifier | 작은 쪽 면적의 **30%** 초과 겹침 |

5. **정렬**: 면적 큰 순 → 왼쪽 페이지 위→아래 → 오른쪽 페이지 위→아래 순으로 정렬합니다.

### 6.3 인식 한계

아래 경우에는 빨간 네모가 인식되지 않거나 잘못 인식될 수 있습니다.

| 상황 | 원인 | 해결 방법 |
|------|------|-----------|
| 흐릿한/옅은 빨간색 | 채도가 설정값 미만 | 채도 하한을 낮추세요 |
| 어두운 빨간색 | 밝기가 설정값 미만 | 밝기 하한을 낮추세요 |
| 주황/분홍에 가까운 색 | Hue 범위 밖 | 이미지 색상을 조정하세요 |
| 너무 작은 네모 | 면적 < 최소 영역 | 최소 영역을 낮추세요 |
| 극단적으로 가느다란 네모 | 종횡비 ≥ 20:1 | 테두리가 너무 얇지 않은지 확인하세요 |
| 두 네모가 하나로 합쳐짐 | 빨간 픽셀이 상하좌우로 닿아 있음 | 네모 사이에 최소 1px 간격을 확보하세요 |
| 별도인 두 네모가 병합됨 | 바운딩 박스 겹침 > 20~30% | 네모 간 간격을 더 넓히세요 |

## 7. 문제 해결 가이드

### Q: 박스가 하나도 감지되지 않습니다.

1. **채도/밝기 하한**을 낮춰보세요 (예: 30~50).
2. **최소 영역**을 100으로 낮춰보세요.
3. 이미지의 빨간색이 실제로 순수한 빨간색인지 확인하세요. 주황색이나 분홍색은 감지되지 않습니다.

### Q: 박스가 너무 많이 감지됩니다.

1. **최소 영역**을 높여보세요 (워크북의 경우 25,000 권장).
2. **채도/밝기 하한**을 높여보세요 (예: 150~200).
3. **최대 박스 수**를 제한하세요.

### Q: 두 개의 박스가 하나로 합쳐집니다.

- 원본 이미지에서 두 빨간 네모의 테두리가 **상하좌우로 닿지 않도록** 최소 1px 이상 간격을 확보해야 합니다.
- 대각선으로만 닿는 것은 괜찮습니다 (4-connectivity).

### Q: 내보낸 좌표가 소수점으로 나옵니다.

- 정상적으로는 정수(소수점 버림)로 내보내집니다. 사이드바에서 직접 수정한 값이 소수인 경우 자동 변환됩니다.

### Q: 해상도 배율을 변경했더니 좌표가 달라졌습니다.

- 배율 변경 시 기존 좌표가 새 배율에 맞게 자동 재계산됩니다. 이는 정상 동작입니다.

### Q: Excel 파일이 열리지 않습니다.

- 테마 XML이 포함된 정상적인 XLSX 형식으로 내보냅니다. Excel 2010 이상 또는 Google Sheets에서 열 수 있습니다.
